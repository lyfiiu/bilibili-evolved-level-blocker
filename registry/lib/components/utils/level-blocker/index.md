按 B 站用户等级自动屏蔽低等级 UP 主发布的视频与评论区低等级账号的评论/回复，在各个界面减少低质量或小号刷屏内容。

### 功能说明

- **视频与动态屏蔽**：覆盖首页推荐、分区页、热门/排行榜、搜索结果页、视频播放页右侧/底部相关推荐、动态页 (`t.bilibili.com`) 及个人空间投稿列表；也可配合 Bilibili Evolved 自带视频卡片使用。
- **评论区屏蔽**：兼容 B 站新版 Shadow DOM 评论区 (`v3`)、Vue 3 评论区 (`v2`) 及旧版 DOM 评论区 (`v1`)，同时支持主评论与楼中楼回复的过滤。
- **屏蔽方式**：
  - `完全隐藏`：直接隐藏符合屏蔽条件的视频卡片与评论。
  - `折叠占位提示`：在原位显示一条紧凑提示条，点击后可临时展开查看原内容。
- **白名单与防误伤**：
  - 自动放行当前登录账号自身；
  - 支持开启「放行已关注账号」；
  - 支持在「UID 白名单」中填写需要豁免的用户 UID（逗号、空格或换行分隔）。
- **性能优化与防风控**：
  - 评论区评论直接读取评论数据中的等级字段，零额外请求；
  - 视频 UP 主等级通过本地缓存（默认 7 天，Lv.6 自动延长至 30 天）、请求去重、批量名片接口与低并发队列查询，避免频繁请求触发风控。
